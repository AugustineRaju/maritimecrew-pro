# MaritimeCrew Pro — Static UI Prototype

A responsive, static-data maritime crew and fleet compliance dashboard inspired by the supplied concept screenshot.

## Run
Open `index.html` in a modern browser. No installation or server required.

## Features
- Dashboard and 10 sidebar sections
- Crew alerts, vessel tables, compliance indicators
- Search/filter, clickable records, sample report download
- Sample data only. No real AI, authentication, persistence, or maritime compliance validation.

## Publish with GitHub Pages
1. Create a public GitHub repository named `maritimecrew-pro`.
2. Upload `index.html`, `style.css`, and `app.js` to its root.
3. Go to Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
4. Your demo will appear at `https://YOUR-USERNAME.github.io/maritimecrew-pro/` after deployment.

This is a prototype and is not intended for real maritime operational use.
